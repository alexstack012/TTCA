# Character portraits

Place optimized WebP or AVIF portraits here and name them after the entity source key, for example `ireena-kolyana.webp`.

Store a root-relative URL in PostgreSQL:

```text
/assets/images/characters/ireena-kolyana.webp
```

Angular copies `public` to the root of development and production builds. Files added here require a new deployment before a hosted application can display them.
